# Expense Tracker 

A console-based Expense Tracker built with Python that helps users record and manage their daily expenses. The project stores data in a CSV file and provides features to add, view, search, update, delete, and analyze expense records.

This project was created to strengthen my understanding of Python programming, Object-Oriented Programming (OOP), CSV file handling, exception handling, and basic data analysis.

---

## Features

* Add a new expense
* View all saved expenses
* Search expenses by Expense ID
* Search expenses by Date
* Search expenses by Category
* Update existing expense records
* Delete expenses
* Calculate total expenses
* Generate category-wise expense summary
* Generate monthly expense summary
* Analyze expense data using Pandas
